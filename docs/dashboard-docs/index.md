# Icefabric Dashboard Documentation

Welcome to the Icefabric Dashboard documentation.
The dashboard is an interactive [Streamlit](https://streamlit.io/) application designed to explore, subset, and visualize hydrologic datasets stored in the Icefabric ecosystem.

The dashboard provides:

- Simple access to NGWPC Hydrofabric network data
- Tools to explore HEC-RAS Cross‑Sectional datasets
- Streamflow observation visualizations and hydrograph interactions
- Downloadable datasets for local analysis
- Options to connect either the AWS Glue Iceberg catalog or a local SQLite-backed catalog

Use the sidebar navigation to learn how to run the dashboard, understand each page, and update/extend it.
